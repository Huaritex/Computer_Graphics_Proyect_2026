# Guion de demostración

## Preparación

Ejecutar `npm run dev`, abrir la aplicación y mantener visible la consola.

## Secuencia

1. Presentar el plano del proyecto y el problema ilustrativo.
2. Mostrar las dimensiones en milímetros y la conversión a unidades de escena.
3. Regenerar la sección y señalar que la distribución es académica.
4. Seleccionar vigas o barras cuando estén integradas en la interfaz.
5. Activar X-Ray y wireframe.
6. Ejecutar el despiece y restaurarlo.
7. Mostrar el análisis de separación y explicar que no constituye certificación.
8. Abrir Spector.js y capturar al menos una escena opaca y una transparente.
9. Explicar el recurso externo pendiente y su carga local.

## Cierre

Resaltar la separación entre geometría, validación y presentación; mencionar las limitaciones normativas y de datos.
