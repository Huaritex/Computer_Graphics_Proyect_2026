# Decisiones técnicas

## Vite

Se usa por arranque rápido, módulos ES y construcción reproducible.

## Three.js

Three.js proporciona geometría, cámara, luces, raycasting y carga glTF en una API adecuada a fines académicos.

## GSAP

Se reserva para despiece reversible y transiciones interpoladas. Las posiciones finales deben conservarse para restaurar la escena.

## Vitest

Las pruebas usan Vitest porque comparte el ecosistema JavaScript y permite ejecutar casos puros sin navegador.

## Validación defensiva

Se rechazan números no finitos, negativos y recubrimientos incompatibles. Los resultados se reportan con mensajes legibles.

## Limitaciones

No se implementan verificación normativa, cálculo estructural, unión soldada, plastificación, fatiga, fisuración ni control de tolerancias. No reemplaza software estructural ni criterio profesional.
